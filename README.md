# Trader Restock Refresh

Refreshes the open trader screen when that trader restocks and hides the restock popup. For SPT 4.1.x.

## Install

Extract the zip from [Releases](https://github.com/FenrirTheGray/spt-trader-restock-refresh/releases/latest) into your SPT folder.

## Build

```
dotnet build Server -c Release
dotnet build Client -c Release -p:GameDir=C:\path\to\SPT
```
